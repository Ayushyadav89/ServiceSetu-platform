# ServiceSetu

ServiceSetu is a full-stack web application that connects customers with verified local service providers on a single platform. It allows users to discover, book, and manage services such as electricians, plumbers, carpenters, cleaners, tutors, and other professionals with ease.

The platform focuses on providing a seamless booking experience, secure authentication, and efficient service management for both customers and providers.

---

## 🚀 Features

### 👤 User Features

* User Registration & Login
* Secure Authentication
* Browse Available Services
* Search & Filter Services
* Book Service Appointments
* View Booking History
* User Profile Management
* Responsive UI

### 🛠 Service Provider Features

* Provider Registration
* Manage Service Listings
* Accept or Reject Bookings
* Update Availability
* Track Service Requests

### 🛡 Admin Features

* Manage Users
* Manage Service Providers
* Manage Services
* View Bookings
* Dashboard Analytics

## ⚙ Installation

### Clone the Repository

```bash
git clone https://github.com/yourusername/ServiceSetu.git
```

```bash
cd ServiceSetu
```

### Install Dependencies

Frontend

```bash
cd client
npm install
```

Backend

```bash
cd ../server
npm install
```

---

## ▶ Running the Project

### Start Backend

```bash
npm run dev
```

### Start Frontend

```bash
npm start
```

The application will run locally on:

Frontend

```
http://localhost:3000
```

Backend

```
http://localhost:5000
```

---

## 📌 Environment Variables

Create a `.env` file inside the server folder.

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```
